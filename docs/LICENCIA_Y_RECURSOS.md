# Licencia y procedencia

No se ha elegido una licencia de distribución para el proyecto. `package.json` declara `UNLICENSED`; no se conceden aquí permisos de reutilización del código o las ilustraciones. La persona titular del proyecto debe elegir y aprobar una licencia antes de presentarlo como software de código abierto. No se ha añadido una licencia MIT o similar de forma automática.

Las bibliotecas instaladas mantienen sus propias licencias en sus paquetes. El repositorio conserva `pnpm-lock.yaml` para identificar las versiones. No se versionan las dependencias.

Los tres PNG de `public/art/` son ilustraciones creadas para el proyecto durante su elaboración asistida. Representan Aurora y personajes ficticios; no son fotografías de territorios ni personas identificadas. Los iconos proceden de Lucide. Los sonidos de interacción se sintetizan localmente mediante Web Audio; no se incluyen canciones comerciales.

Las referencias MGA/DNP y ODS sirven de soporte conceptual, no implican afiliación, aval o certificación de esas organizaciones. Los marcos ficticios y las magnitudes simuladas están etiquetados. Antes de una distribución pública, revisar la procedencia y los derechos del material incorporado en cambios futuros.
